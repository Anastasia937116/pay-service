# Pay Service – Этап 1

REST API для работы с банковским счетом.


## Реализованный функционал

На первом этапе реализованы следующие операции:

- Получение баланса пользователя (getBalance)
- Пополнение счета (putMoney)
- Снятие средств (takeMoney)
- Перевод средств между пользователями (transferMoney)
- Получение списка операций (getOperationList)

### Дополнительно реализовано

Помимо требований задания, в проекте:

- Реализовано хранение истории операций в отдельной таблице `pay_operation`
- Добавлена фильтрация операций по диапазону дат
- Разделены причины ошибок (некорректная сумма, пользователь не найден, недостаточно средств и т.д.)
- Использована транзакционность (`@Transactional`) для обеспечения целостности данных
- Настроена автоматическая инициализация базы данных через `schema.sql` и `data.sql`
- В репозитории присутствует dump базы данных для упрощения развертывания проекта

## Используемые технологии

- Java 21
- Spring Boot 3.2.5
- Spring Data JPA
- PostgreSQL
- Maven

## Структура базы данных

В проекте используются две таблицы:

### users_balance
- id
- user_id (уникальный)
- balance

### pay_operation
- id
- user_id
- operation_date
- operation_type
- amount

## Инициализация базы данных

- schema.sql – создание таблиц
- data.sql – заполнение тестовыми данными

## Пример запроса

GET /api/getBalance?userId=1

Ответ:

{
"code": 1,
"message": "Баланс получен",
"balance": 1000.00
}
